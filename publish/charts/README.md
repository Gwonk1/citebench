# citebench charts (preliminary, Sept 22 2026)

Generated by `make_charts.py` from `results/report_150.md` (headline slice: questions <= q0150).
The name-mismatch / absent-quote split for chart 2 is not printed in the report, so it is read
read-only from `results/results.db` on the same slice. The script exits if the DB and report
disagree on cites, graded count or misgrounded_rate. Excluded: gemini-3.8-flash mcp (37 of 40 answers errored).

## Regenerate

```
cd ~/projects/citebench
python3 report.py --max-qid q0150 --out results/report_150.md     # after any regrade
uv run --no-project --with matplotlib python publish/charts/make_charts.py
```

Every chart is written as SVG (text kept as text, title and description in the metadata) and as a 2x PNG
(2400 px wide), light and `_dark`. Palette: the dataviz skill's reference palette, run through
`validate_palette.js` in both modes (all checks pass; aqua and yellow are under 3:1 on the light surface,
so every segment is covered by a legend and the numbers below). Error bars are 95% Wilson intervals:
from n_cites for citation-level rates, from graded questions for gold_recall.

| file | chart |
|---|---|
| `headline_bars.{svg,png}`, `headline_bars_dark.*` | 1. misgrounded_rate per model and arm, fabricated_rate as a diamond |
| `fab_vs_misgrounded.{svg,png}`, `_dark.*` | 2. bare models: what goes wrong (invented vs misgrounded) |
| `bare_vs_mcp.{svg,png}`, `_dark.*` | 3. the same model with and without tools, 3 small multiples |
| `index_gap.{svg,png}`, `_dark.*` | 4. Fable's 755 citations and the reporter-pagination gap |
